# Decision #001

## 主題

交易數量單位

## 決策

系統內部一律使用「股數 (Share)」。

例如：

- 00712：125000 股
- 2330：3000 股

## 原因

1. 天然支援零股交易。
2. ETF、股票、美股皆可共用。
3. 資料庫設計更單純。
4. 所有計算（平均成本、持股、配息）都統一使用股數。

## UI

畫面可依需求顯示：

- 125,000 股
- 125 張
- 125 張（125,000 股）

資料儲存方式不變。


# Decision #003

## 商品建立方式

商品（Asset）採獨立管理。

第一次新增商品時，可輸入商品代號，由系統查詢公開資料，自動帶入：

- 商品名稱
- 商品類型（ETF / 股票）
- 市場（TWSE / TPEx）

使用者確認後建立。

之後所有交易都選擇既有商品，不重複建立。

## 原因

- 避免重複商品。
- 避免代號輸入錯誤。
- 方便未來串接即時報價、配息資料等功能。
